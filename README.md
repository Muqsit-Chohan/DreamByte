# DreamByte Studio & Nexsora OS Website

This is the official company website for DreamByte Studio, built with React, Vite, and Tailwind CSS. It serves a dual purpose: acting as the corporate landing page for DreamByte and as the product showcase for our flagship AI-powered platform, **Nexsora OS**.

- **Live Site**: [dreambyte.space](https://dreambyte.space)
- **Nexsora OS App**: [nexsoraos.online](https://nexsoraos.online)


## ✨ Features

- **Dynamic Page System**: Switches between "Home" and "Projects" pages using React state without a full page reload.
- **Interactive & Animated UI**: Uses **GSAP** for scroll-triggered animations (like the parallax hero text) and **Framer Motion** for smooth UI animations.
- **Component-Based Architecture**: Built with reusable React components for clean and scalable code.
- **Responsive Design**: Looks great on all devices, from mobile to desktop.
- **Detailed Founder Profiles**: Includes a team overview and individual profile pages for each founder, accessible via URL hash (e.g., `#safeer`).

## 🛠️ Tech Stack

- **Framework**: React
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: GSAP (GreenSock) & Framer Motion
- **Icons**: Lucide React

## 🚀 Getting Started

Follow the steps below to set up the project on your local machine.

### Prerequisites

You need to have Node.js and npm (or yarn) installed on your system.

- Node.js (v18.x ya usse naya version)
- npm / yarn

### Installation

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/your-username/your-repo-name.git
    ```

2.  **Navigate to the project directory:**
    ```sh
    cd your-repo-name
    ```

3.  **Install dependencies:**
    ```sh
    npm install
    ```

### Development Server

To start the local development server:

```sh
npm run dev
```
